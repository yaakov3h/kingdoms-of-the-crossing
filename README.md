# ממלכות המעבר

## מידע וקרדיט

ממלכות המעבר, משחק אסטרטגיה בתורות בהשראת Heroes III.

- יוזמה והובלת הפרויקט: יעקב המאירי.
- פיתוח ועיצוב: נועה.
- איורים שנוצרו במיוחד למשחק.
- גרסת סולו עם שמירות מקומיות וייצוא וייבוא של שמירות.
- משחק חי: https://kingdoms-of-the-crossing.pages.dev/

משחק אסטרטגיה מקורי בסולו: חקירת עולם, בניית עיר, כלכלה, גיבורים וקרבות בתורות. ארבע סיעות עם שמונה יחידות בכל סיעה. ללא שירות בתשלום.

## הרצה מקומית

Node.js22ומעלה:

```sh
npm ci
npm run dev
```

פותחים את הכתובת שהפקודה מציגה. אין צורך בשרת נוסף לסולו.

```sh
npm run build
npx vite preview --host 0.0.0.0
```

## משחק

- יוצרים מערכה נפרדת, בוחרים סיעה ועולם24×24או32×32.
- הקשה על יעד גלוי בוחרת את המסלול הזול לפי השטח. הגיבור צועד עד היעד, תחילת קרב או סיום נקודות התנועה. אין צורך בחצי כיוון.
- גוררים את המפה, צובטים להגדלה בנייד או משתמשים בגלגלת/כפתורי הזום. כפתור מסך מלא תלוי בתמיכת הדפדפן.
- סיום יום מחדש תנועה, גובה הכנסה ומפעיל את ממלכות המחשב.
- העיר מאפשרת מבנה אחד ביום. מבנים מתקדמים דורשים מבנים קודמים; מלאי הגיוס גדל בכל שבוע.
- כל גיבור מוביל עד שש יחידות נפרדות. אלה אינן ערימות של מאות חיילים.
- בקרב מקישים על יחידה, ואז על עמדה סמוכה או אויב בטווח. לכל סוג יחידה יכולת חד-פעמית. אפשר לבחור קרב אוטומטי, עם אבדות אמיתיות, או לסגת.
- הניצחון מגיע מכיבוש בירות המחשב. אפשר להפסיד במצור על הבירה.

## קובץ עצמאי למחשב

```sh
npm run build:portable
```

נוצר `kingdoms-solo-offline.html`, המכיל את הקוד ואת כל87האיורים. פותחים בדפדפן. נבדק ב-Chromium במחשב, כולל שמירה וטעינה מחדש, ללא רשת. פתיחת קובץ HTML מהורדה בטלפון לא נבדקה. שמירות של קובץ מקומי, כתובת שרת והגרסה הישנה אינן עוברות אוטומטית ביניהם; השתמשו ביצוא ויבוא במקום שיש תמיכה בכך. שינוי מיקום/שם הקובץ עלול לשנות את מקום השמירה.

## שמירות

השמירה אוטומטית בדפדפן ובמכשיר בלבד. מחיקת נתוני האתר עלולה למחוק אותה. מתפריט המשחק אפשר לייצא קובץ גיבוי ולייבא אותו. יבוא מוסיף שמירה ואינו דורס אחרות. שמירות ישנות שומרות את חוקי התנועה הישנים שלהן. החלפת כתובת האתר אינה מעבירה שמירות אוטומטית.

## מבנה הקוד

- `src/engine.ts`: מצב ופקודות משחק, ללא תלות בממשק.
- `src/catalog.ts`, `src/roster.ts`: שטח, תנועה, סיעות ויחידות.
- `src/storage.ts`: בדיקה, יצוא ויבוא של שמירות.
- `src/main.ts`, `src/scene.ts`: ממשק וציור.
- `public/art`: איורים מקוריים שנוצרו למשחק, ללא נכסי Heroes.
- `server`, `src/paired-*`: תשתית ניסיונית מהשלב הקודם, אינה חלק מגרסת הסולו הנמסרת כעת.

## בדיקות היסטוריות

הקבצים `ui-deep`, `ui-controls`, `ui-campaign` וחלק מבדיקות הזוגי נשמרו מהשלב הקודם. הם מתעדים התנהגות של הממשק הישן ואינם רשימת הבדיקות להרצה בגרסה זו. השתמשו ברשימה שלמעלה עבור הסולו הנוכחי.

## גבולות

משחק זוגי/קבוצתי, חשבונות ושמירה ברשת נדחו במפורש. שרת חיצוני כבוי כברירת מחדל. אין להפעיל פרסום ציבורי או שירות בתשלום מכוח הוראות הרצה אלה. הריפו הוא גיבוי קוד, לא שמירת משחק ולא אתר זמין. הגרסה הקודמת שפורסמה לא משתנה אוטומטית בעקבות בנייה מקומית. יעדי הבנייה והבדיקה ב-`BUILD-SCOPE.md`.
