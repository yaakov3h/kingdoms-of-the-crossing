# ממלכות המעבר, פיתוח עצמאי מקומי

פיתוח ב-Phaser. לא פורסם ולא מחובר לחשבון Cloudflare. הגרסה הקודמת לא שונתה.

## הרצה

- `npm ci`
- `npm run dev` לסולו במכשיר.
- בחלון נוסף: `WRANGLER_SEND_METRICS=false npx wrangler dev --local --ip 127.0.0.1 --port 8787 --persist-to .local-server`
- בדיקת החדרים נמצאת בתפריט. שני דפדפנים נפרדים יכולים ליצור ולהצטרף לחדר מקומי.
- לא להריץ פקודת פרסום. `workers_dev` כבוי בכוונה.

## בדיקות

- `npm test`: מנוע הסולו, תקינות שמירות, חדרים וחוקי שני הצבאות.
- `npm run build`: בדיקת TypeScript ובניית האתר.
- `node ui-touch.mjs`: בדיקת צביטה בשתי אצבעות באמולציה, לא מכשיר פיזי.
- `node ui-tactical.mjs`: קרב ידני מלא דרך בחירת תא ופקודה.
- `node ui-human-battle.mjs`: מצור מנקודת פתיחה חוקית וקרב מלא בין שני דפדפנים, כולל טעינה מחדש בזמן המתנה.
- `node ui-check.mjs`: מסכים ושמירה מקומית.
- `node ui-deep.mjs`: יצוא/יבוא קובץ ממשי, שמירה בזמן קרב, מסכים וגדלי תצוגה.
- `node server-check.mjs`: שרת מקומי, הרשאות, התנגשות גרסאות, ביצוע כפול, שחזור אחרי אתחול.
- `npx tsx campaign.ts`, ואז `START=0 END=85 node ui-campaign.mjs` ו-`START=85 END=175 node ui-campaign.mjs`:175פעולות של מסע מלא דרך הממשק עד ניצחון ביום51.
- `node ui-paired-panels.mjs`: עיר, מבנים, צבא, כלכלה, גיבוי ושחזור גישה בדפדפן שלישי והחלפת מפתח.
- `node ui-bootstrap-recovery.mjs`: אובדן תשובות יצירה והצטרפות, הפעלה מחדש וניסיון בטוח.
- `node ui-paired.mjs`: שני דפדפנים נפרדים, שני צבאות, החלפת תור ושחזור.

## גבולות הגרסה

הסולו מעביר את חוקי הגרסה הקודמת. שמירות אישיות הן בדפדפן ובמכשיר בלבד. שם פרופיל אינו אימות זהות. יצוא יוצר קובץ גיבוי ויבוא מוסיף שמירה במקום חדש.

הזוגי הוא שכבת פיתוח נפרדת ולא גרסה מלאה: עולם משותף, שני צבאות אנושיים נפרדים, משחק בתורות גם כשהאחר לא מחובר, קרב אנושי שממתין לכל פקודה של הצד השני, משחק שיתופי עם יעד מצודה ומשחק עימות. מדיניות הקרב עדיין ניסיונית ולא אושרה לגרסה הסופית. מבנים מתקדמים, גיוסים מיוחדים ויכולות ארבע הבריתות כבר קיימים ונבדקו. ציוד שרידים קיים ונבדק גם במסלול איסוף וציוד דרך הדפדפן. לכל שחקן עד שלושה מפקדים, עם צבאות, מיקומים, פעולות וציוד נפרדים. גיוס מפקד, העברת יחידה, תנועה ושחזור נבדקו בדפדפן מנקודת פתיחה חוקית. איזון וגרפיקה מלאה לזוגי עוד לא הושלמו.

השרת המקומי שומר מצב סמכותי, מפתחות גישה מגובבים, הזמנה חד-פעמית, מספר גרסה ומזהי פקודות. הממשק שומר פקודה לא-מאומתת במכשיר ומציע ניסיון חוזר עם אותו מזהה. יש גיבוי גישה פרטי ושחזור מקובץ במכשיר אחר, וחידוש הזמנה לפני הצטרפות. אין שחזור ללא קובץ או מכשיר מחובר. קיימת החלפת מפתח שמבטלת גישה במכשירים ובקבצים קודמים, כולל בדיקת תשובה שאבדה אחרי החלפה. אין עדיין תפוגת חדרים או ניקוי חדרים. הגנות בקשה20KB, מצב חדר1MB וקצב120בקשות לדקה בחלון קבוע הנשמר לחדר קיים הן חלקיות ואינן תחליף לשער כניסה ולמכסה כללית. איבוד מפתח הדפדפן עלול לאבד גישה. אין למסור לבדיקה חיצונית לפני השלמתם והכרעת הרשאות פרסום.

במצב עימות השרת מסנן מיקום צבא לא-גלוי, משאבי היריב ומפתו מהתשובה, ולא מסתפק בהסתרה גרפית. המפתחות אינם שמורים בקוד המקור ואין לשמור קבצי מצב שרת מקומי או נתוני דפדפן בארכיון.

## מה עוד דרוש

- הרחבת מסעות מלאים לבריתות נוספות, העברות, קרבות מיוחדים ומכשיר פיזי. מסע משמר מאדים עם יריב אחד נבדק דרך הממשק עד ניצחון.
- הגנת קצב/קיבולת, מחיקת חדר ושחזור גישה. ניתוק לאחר קליטת פקודה וניסיון חוזר עם אותו מזהה נבדקו בדפדפן; תחרות גרסאות נבדקה בשרת המקומי.
- ממשק קרב גדול יותר, ציורי יחידות ברורים יותר, סמלי יכולות ורמזי טווח.
- השלמת חוקי הזוגי, אישור מדיניות המתנה בקרב ויעדי ניצחון.
- גשר יצוא מאומת מהמקור של השמירה הישנה. דפדפנים אינם מעבירים שמירה בין מקורות אוטומטית.
- רק אחרי אישור נפרד: חשבון, תנאי שירות, קהל מורשה ופרסום. אין חיוב או שדרוג בתשלום.

שרת האינטרנט כבוי כברירת מחדל גם ברמת הקוד, לפני הקצאת חדרים. אין להפעילו לפני הכרעת חשבון, קהל, גישה ומכסות. הגנה זו אינה בקרת גישה מלאה ואינה מחליפה שער כניסה.

בדיקת מסע שיתופי מלא: `npx tsx shared-campaign.ts`, ואז `START=0 END=35 node ui-coop-campaign.mjs` והמשך מקטעים35-70,70-105,105-140,140-175,175-213. קובץ הגישה הפרטי של הבדיקה נשמר מחוץ לתיקיית המקור ואסור לצרף אותו לארכיון. הבדיקה המקומית עברה213פעולות עד ניצחון צוות ביום62, אינה הוכחת איזון.

בדיקת מפקדים: `node ui-paired-commanders.mjs`. בדיקת ציוד מהתחלה חוקית: `node ui-paired-equipment.mjs`. קרב נגד משלחת לא פעילה, ציוד נפרד וסינון ערפל מכוסים בבדיקות חוקים. המסע השיתופי המלא בדפדפן הורץ שוב לאחר תוספת המפקדים ועבר213פעולות עד ניצחון ביום62. המסע משתמש במפקד הראשי; מסלול המפקד הנוסף נבדק בנפרד. גם הקרב האנושי הורץ שוב ועבר45פקודות בשני דפדפנים.

לקרב אנושי במקטעים: `SETUP_ONLY=1 node ui-human-battle.mjs`, ואז `RESUME=1 MAX_COMMANDS=12 node ui-human-battle.mjs` עד סיום. זהו קובץ בדיקה מקומי פרטי מחוץ לתיקיית המקור, לא מנגנון חשבונות.
