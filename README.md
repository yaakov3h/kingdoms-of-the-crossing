# ממלכות המעבר
משחק אסטרטגיה מקורי, בבניית גרסת סולו רחבה. ריפו פרטי, ללא אתר פתוח לציבור.

הפיתוח המקומי כולל קוד, גרפיקה ובדיקות. סנכרון קובצי המקור לריפו עדיין בהכנה. אין כאן עדיין גרסת משחק להרצה.
שמירות המשחק בדפדפן ובמכשיר בלבד. משחק זוגי, חיבור שרת ושמירות רשת נדחו לשלב הבא.
אין תשלום או שירות ענן נוסף בגרסה הזאת.
